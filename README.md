# FBLA Connect
**FBLA Mobile Application Development | 2025–2026**

## Overview
FBLA Connect is a native Android app designed to give FBLA members one central place for events, news, resources, and social links. The goal is to replace scattered websites, emails, and social media with a single, easy-to-use mobile platform.

---

## The Problem
FBLA information is spread across multiple platforms, making it easy for members to miss important updates and events.

---

## Our Solution
FBLA Connect brings everything together in one app:
- Member profiles
- Event calendar
- Resource hub
- News and announcements
- One-tap access to official FBLA social media

---

## Development Details
- **Platform:** Android
- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **Design:** Material Design with FBLA blue and gold branding
- **Planning:** Wireframes and user flow diagrams created before development

---

## Data & Security
- **Firebase Firestore** for cloud-based data storage
- Encrypted local storage for user sessions
- Input validation on login and registration forms

---

## Future Improvements
